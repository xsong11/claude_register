# 账号工作台

账号按「注册工作台 → 待检测 → 账号库」流转。每个工作区都按 Claude 和 ChatGPT 分开。同一邮箱可以有两条平台账号记录，分别管理分组、备注、代理、会话、套餐和账号状态；邮箱收件凭据和原有 OKBrowser 绑定仍按邮箱共享。

- 注册工作台：导入待注册邮箱或 Outlook 收件凭据，查看任务与失败原因，按平台重试。
- 待检测：注册取得会话后自动出现。检测仅查询平台，确认可用或收到明确的封禁结果后进入账号库；登录失效、请求受阻和其他无法判定的情况留待复查。可以在详情替换凭据后再检测。
- 账号库：复查实际套餐和会话、修改管理状态，或在确认导入时把已有凭据直接放入账号库。也可以将已有凭据导入待检测。导入先预览，已有平台记录跳过。

「账号状态」为正常、封禁、停用或其他；点选后立即生效，详情保留状态历史。分组和账号状态不会移动账号。账号库内后来检测失败的账号仍留在账号库，检测成功也不会取消人工状态。非正常账号和待检测账号不会自动领取或参与 sub2api 同步。

检测、邮件和 OKBrowser 都可以直接从列表行打开；点账号状态即可看到所有状态选项。也可以在详情顶部修改，或勾选多个账号后批量修改。凭据和状态历史直接展示，凭据显示摘要，可一键复制。

账号库可在行内直接标记已领取或取消标记。已领取的账号不会被自动重复分配。

登录失效、请求受阻或检测失败时，可以点账号行上的「同步」，或筛选「需要修复」后勾选批量同步。同步只读取已绑定窗口里的会话；平台验证有效且邮箱相符才写回。窗口没有登录或登录了别的账号时，原凭据保留，结果会说明原因。可以先用「打开 OKBrowser」在对应窗口手动登录，再同步。

Claude 使用账号的 sessionKey 和绑定代理读取组织、套餐、订阅 KYC 和 Portal KYC。组织无法确定时不会猜测。Portal「未见限制」表示该组织的响应明确未返回验证限制，不表示身份验证已通过。ChatGPT 使用自身会话或访问凭据检测，不走 Claude 的 KYC 查询。两边的套餐都以平台明确返回为准。

「套餐到期时间」来自 Claude 的套餐结束时间或 ChatGPT 的权益到期时间。接口没有返回日期时显示「平台未提供」，未能查询到订阅详情时显示「未获取」。下次扣费时间和登录凭据过期时间都不会作为套餐到期时间。已有账号可点「检测」补查。

首次启动时，面板在原数据库中追加平台记录和状态历史表，保留旧账号凭据、注册历史和领取标记。已有凭据归入账号库；没有可靠平台证据的邮箱归入注册工作台的「待归类」。旧会话失效不会变成封禁；已有明确 ChatGPT 封禁标记只归到 ChatGPT。
